
# Sales Data Entry & Analysis Dashboard

## 📊 Project Overview
An interactive Sales Dashboard built in Excel to analyze sales performance across regions, products, and months.

## 🛠️ Tools Used
- Microsoft Excel (Data Cleaning, Formulas, Pivot Tables, Charts, Slicers)

## 🔍 Steps Followed
1. Data Cleaning – Fixed date formats, removed duplicates, checked for blanks
2. Data Entry & Formatting – Used Excel Tables, formulas (Quantity × Unit Price)
3. Pivot Tables – Region-wise, Product-wise, and Month-wise sales analysis
4. Pivot Charts – Column charts for Region & Product, Line chart for Monthly trend
5. Dashboard – Combined KPIs (Total Sales, Orders, Quantity, Average Sales) with charts and interactive Slicers (Region & Product)

## 📈 Key Insights
- Laptop is the highest-selling product (₹9,00,000)
- East region generated the highest sales (₹4,89,700)
- Total Sales: ₹13,36,900 across 50 orders
